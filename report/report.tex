\section{Постановка задачи}

Необходимо найти площадь фигуры, ограниченной данными тремя кривыми, лежащей на заданном отрезке. Гарантируется, что кривые попарно пересекаются на данном отрезке. 
\begin{itemize}
    \item Для нахождения точек пересечений требуется реализовать численный метод нахождения корней. Решение реализует два метода (на выбор): метод Ньютона (касательных) и метод хорд.
    \item Для нахождения площади фигуры требуется реализовать метод численного интегрирования. Решение реализует два метода (на выбор): метод трапеций и метод Симпсона (парабол).
\item Отрезок для применения метода нахождения корней должен быть вычислен аналитически.
\end{itemize}
Функции, задающие кривые, и отрезок, на котором лежит фигура, задаются перед сборкой в файле. Функции задаются в обратной польской записи.\\\\
Пример:
\begin{minted}[frame=single, linenos, breaklines=true, fontsize=\small]{text}
0.0 4.0
2 x 4 / tan -
x
0.2 pi *
\end{minted}

\section{Математическое обоснование}

\subsection{Минимальные условия сходимости}
\begin{itemize}
    \item $\exists x_0: f(x_0) = 0$
    \item $f(x)$ непрерывно дифференцируема на отрезке
    \item Начальная точка $x$ достаточна близка к $x_0$
\end{itemize}

Для метода Ньютона желательно соблюсти все условия Фурье:
\begin{itemize}
    \item $f'(x) \neq 0$ на отрезке
    \item $f''(x)$ не меняет знак на отрезке
    \item начальная точка $x_0$ с того конца отрезка, где $f(x_0)\cdot f''(x_0) > 0$,
\end{itemize}
так как при соблюдении лишь минимальных условий метод может уйти за пределы отрезка, сойтись к другому корню или не сойтись вовсе.~\cite{math}\\\\

Площадь заданной фигуры должна быть вычислена с точность $\varepsilon$. В некоторой окрестности точки пересечения, которую мы ищем с точностью до $\varepsilon_1$, функции эквивалентны своим касательным в этой точке.~\cite{math} Значит, при смещении границы интегрирования, изменение значения интеграла будет пропорционально квадрату смещения.
Общая площадь фигуры равна комбинации трех интегралов с некоторыми знаками; общая погрешность может достигать $3\varepsilon_2 + 2\varepsilon_1^2 \leq 0.001$ по условию. Возьмем $\varepsilon_2 = \varepsilon_1 = 0.0001$, $3\varepsilon_2 + 2\varepsilon_1^2 = 0.0003 + 0.0000002 \approx 0.0003 \leq 0.001$.\\

Для вычисления интеграла с определенной точностью было использовано правило Рунге. Метод Симпсона имеет порядок точности 4, метод трапеций имеет порядок точности 15. Оценка погрешности равна разнице между двумя площадями, посчитанными с разной точностью, деленной на порядок точности. Поэтому количество разбиений в обоих методах экспоненциально повышается, пока оценка не станет меньше $\varepsilon_2$.\\

После нахождения точек, сначала определяется верхняя/нижняя ограничивающая кривая. Это кривая, которая не пересекает другие в средней (по оси $x$) точке пересечения. Определив, лежит ли она ниже или выше этой точки, мы либо вычитаем ее интеграл из интегралов двух других функций, либо наоборот:\\\\
$S = sign \cdot (\int_a^b f_1(x)\,dx - \int_a^{x_1} f_2(x)\,dx - \int_{x_1}^b f_3(x)\,dx)$,\\\\
где sign равен 1, если кривая выше $x_1$, и -1, если ниже.

\end{gathered}

$$
\begin{gathered}
\int x\,dx = \frac{1}{2} x^2 + C\\
\int -x+1\,dx = -\frac{1}{2}x^2+x + C\\
\int (x-0.5)^2\,dx = \frac{1}{3}(x-0.5)^3 + C\\\\
\end{gathered}
$$

$$
\begin{gathered}
\frac{1}{2}\cdot(0.25 - (1 - \frac{\sqrt{3}}{2})^2) \approx 0.116\\
-\frac{1}{2}\cdot(\frac{3}{4} - 0.25) + (\frac{\sqrt{3}}{2} - 0.5) \approx 0.366 - 0.25 = 0.116\\
\frac{1}{3}\cdot (0.5 - \frac{\sqrt{3}}{2})^3 \approx 0.016\\
\frac{1}{3}\cdot (\frac{\sqrt{3}}{2}-0.5)^3 \approx 0.016\\\\
S \approx 0.116 \cdot 2 - 0.016 \cdot 2 = 0.2
\end{gathered}
$$

\approx 0.166
\end{gathered}
$$

\section{Структура программы и спецификация функций}

Для ознакомления с кодом см. репозиторий [3] и документацию [2].

\subsection{Структура}

\begin{itemize}
    \item in.txt -- SPEC\_FILE, содержащий отрезок и три функции
    \item ast.c и diff\_ast.c -- модули построения Abstract Syntax Tree и его дифференцирования.
    \item rpn2asm.c -- строит дерево функций из SPEC\_FILE, затем на основе дерева и дифференцированного дерева составляет ассемблерные функции в соответствии с cdecl.
    \item funcs.asm -- ассемблерный модуль, составленный rpn2asm.c.
    \item numeric.c -- модуль с реализацией численных методов нахождения корней и интегрирования.
    \item main.c -- ввод и вычисления с применением функций из numeric.c.

\subsection{Реализация}
Построение синтаксического дерева само по себе достаточно просто; но, в связи с тем, что в стеке FPU x87 всего 8 регистров, дерево требует оптимизации, чтобы его высота не превышала количество регистров. Оптимизации включают:
\begin{itemize}
    \item Балансировку цепочек ассоциативных операций
    \item Удаление нулевых узлов и единичных множителей (появляется много после дифференцирования)
    \item Сокращение операций вида $\frac{f(x)}{f(x)} := 1$
    \item Предвычисление операций с константами (иногда появляются после дифференцирования)
\end{itemize}
Затем, на основе дерева строятся ассемблерные функции; дерево обходится в post-order порядке, левый операнд лежит в st1, правый в st0; после применения оператора кладем результат в st0.\\

\section{Анализ допущенных ошибок}

Задание не включало реализацию оператора \^{}; он был реализован, но с нюансами. В FPU x87 нет прямой инструкции для возведения $a$ в степень $b$; есть инструкция fyl2x, вычисляющая $a \cdot log_2(b)$, и инструкция f2xml, вычисляющая $2^x-1$ для $x \in [-1, 1]$; таким образом, $a^b = 2^{b \cdot log_2(a)} = 2^{round(b \cdot log_2(a))} \cdot 2^{b \cdot log_2(a) \% 1}$ (целая и дробная части).\\

Проблемы возникают, когда $a \leq 0$; $log_2(0) = -\infty$, для отрицательных -- nan. Отрицательный аргумент появляется очень часто, когда вычисляется, например, значение $(x-a)^2$ при $x < a$; поэтому в программе полноценно реализовано возведение только в константную степень, которая превращается в обычное перемножение в ходе построения дерева. В Makefile для включения реальной экспоненты нужно установить SAFE\_EXP=0.
